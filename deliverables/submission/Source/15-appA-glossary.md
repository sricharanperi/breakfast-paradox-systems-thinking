# @Glossary and Code Keys {#app-glossary}

## Glossary {#sec-glossary}

Table: Terms used in this document. {#glossary cols=22,78}
| Term | Meaning |
|---|---|
| Absorber | Something that takes up a consequence before anyone has to notice it, such as resale for a student's loss or outside diners for surplus food |
| Archetype | A recurring structure that appears in many systems, such as shifting the burden |
| Balancing loop | A chain of causes that bends back and pushes against change |
| Boundary | The line that separates what is inside the system being studied from what is not |
| Crest | The last quarter hour before the 9:30 close, when the largest share of scans occurs |
| Delay | The time between a cause and its effect |
| First batch | The quantity cooked before service begins; it can be topped up during service and never reduced |
| Foil | A weak concept kept in every test to show how a good concept differs |
| Gate | A pass-or-fail test that a concept must clear before its score counts |
| Iceberg | A way of reading a problem at four depths: event, pattern, structure and mental model |
| Leverage point | A place in a system where a small, well-aimed change has a large effect |
| Mess Cell | The student messaging group on which registrations are resold |
| Registration | The automatic booking of every student for every meal, which the bill follows |
| Reinforcing loop | A chain of causes that bends back and pushes the change further |
| Skip Meal | The portal button that tells the kitchen a student will not attend and returns no money |
| Stable equilibrium | A state that resists change because the forces in it balance; a stable system can be a bad one |
| Top-up | Extra food cooked or brought in during service; it can only add to the first batch |
| Turnout | Scans divided by registrations for a day, weekday, line or time |
