**Consolidated standard now lives in two places:**
- `MEMORY.md` → `feedback_questionnaire_design_standard.md` (persists across sessions)
- `deliverables/phase-1/01-system-context-brief.md` Section 8 (applied directly to the 4 roles)

Section 8 was first rewritten 2026-09-09 using only the HCI/Constantine source, then updated
2026-09-04 once the other two sources landed, adding: the 4-part bias taxonomy self-check
(leading/shallow/personal/unconscious), a "does this question serve a named objective" tightening
pass, live-interview conduct rules (curious-command probing, symmetric neutral acknowledgment,
decoupled encouragement, talk-time awareness), and an explicit prevalence-vs-mechanism-claim
distinction for later write-ups.

This methodology folder is a standing reference — reuse it for every future interview/survey/
experiment in this project, not just this one questionnaire.
